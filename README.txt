MANIFESTATION COMPANION
=========================

Thanks for your purchase! This package contains two ways to run the tool —
use whichever fits you.

1) BROWSER VERSION (easiest, no install)
   - Open manifestation_app.html in any browser (double-click it).
   - Works fully offline with free built-in templates — no account needed.
   - Optional: tick "Personalize with your own Claude API key" for fully
     AI-personalized coaching. Your key stays in your browser's memory
     only — it is never sent anywhere except directly to Anthropic's API.
   - Your practice history is saved in your browser automatically.

2) STREAMLIT VERSION (for local desktop use)
   - Requires Python 3.9+.
   - In a terminal, in this folder, run:
       pip install -r requirements.txt
       streamlit run manifestation_app.py
   - Same 7 tools, same optional Claude API personalization.

THE 7 TOOLS
   - Intention Setting     — clarify your goal and the belief in the way
   - Affirmations          — 4 styles: present tense, grateful, becoming, belief
   - Guided Visualization  — 3, 5, or 10-minute scripts
   - Future Self Letters   — from 3 months to 5 years ahead
   - Aligned Actions       — 7 concrete steps you can take this week
   - Complete Sessions     — quick 5-min or full 20-min combined practice
   - Progress Tracking     — daily streaks and a practice log
